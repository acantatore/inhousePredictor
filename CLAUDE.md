## gstack

Use the `/browse` skill from gstack for all web browsing and browser-based testing.
**Never use `mcp__claude-in-chrome__*` tools.**

| Skill | Purpose |

| `/plan-ceo-review` | CEO/founder-mode plan review — rethink scope and ambition |
| `/plan-eng-review` | Engineering architecture review — lock in execution plan |
| `/plan-design-review` | Designer's eye plan review — rate and fix design dimensions |
| `/design-consultation` | Create a full design system and DESIGN.md |

| `/ship` | Ship workflow — merge, test, bump version, create PR |

| `/qa` | Systematic QA testing with iterative bug fixes |
| `/qa-only` | QA report only — find bugs without fixing anything |
| `/qa-design-review` | Visual design audit on a live site |

| `/retro` | Weekly engineering retrospective |
| `/document-release` | Post-ship documentation sync |
